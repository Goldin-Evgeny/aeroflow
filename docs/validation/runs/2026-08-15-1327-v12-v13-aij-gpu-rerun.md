## 5. Anomalies — stated plainly, not diagnosed

1. **V12 misses its band by more than an order of magnitude** (66.19% vs ≤ 5%), and the
   miss is _converged_: 76.75 → 70.61 → 67.59 → 66.19% across four windows, decaying but
   asymptoting near ~65%, not toward 5%.

2. **No pre-repair GPU baseline exists for V12.** `bands.ts` records V12 as
   `status: 'recording'` with the gate description "CPU gate passes, GPU re-run
   outstanding". This run is the **first** GPU measurement of V12. It therefore cannot be
   attributed to the height-mapping repair — the GPU path may have read this way before it.
   Establishing that requires re-running V12 at the parent commit, which was not done.

3. **`docs/VALIDATION.md:212** states "V12/V13 AIJ Case A at ≥24 cells/building — measured
in band". For V12 that claim is now in tension with a GPU measurement. The same passage
defers to `bands.ts`as the pass/fail source of truth, where V12 is`recording`and not`gated`, so no gated claim is contradicted — but the prose is stale.

4. **V13's steadiness is blocked by a single node.** driftScaled is 2.19% while the raw
   drift is 52.31% concentrated at node 41; the drift index moves among nodes 121, 96, 89,
   105, 40 across windows. q itself is far quieter than the steadiness statistic
   (0.683→0.659, spread 0.040 over nine windows).

5. **q sits on the gate.** The last four windows give 0.643, 0.651, 0.659, 0.659 against a
   0.66 bar, with a mild downward trend from 0.683. Whether the case passes may turn on the
   averaging window rather than on the physics. No verdict is claimed either way.

6. **Both AIJ cases run at near-floor τ** — τ₀ = 0.500223 (V12) and 0.500334 (V13), with LES
   and projected regularization active. These are the same conditions under which D1 records
   the ω⁻ collapse and `a55f4e1` records the regularization anti-dissipation. Recorded as an
   observation only; nothing here tests either mechanism, and no causal claim is made.

7. **The AIJ harness emits no machine-readable config or result artifact.** Everything in §2
   and §3 was recovered from the Playwright trace zip and the accessibility page snapshot,
   because the run wrote no JSON of its own. The m9-closure harness does. This is a gap in
   run-history capture, not a defect in the physics.
